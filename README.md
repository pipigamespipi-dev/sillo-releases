# Sillo 🫠

A caring desktop companion for Windows — it reminds you to move, guides your
exercises, keeps your meds on schedule, celebrates your "firsts", and keeps
you company. Speaks Spanish (rioplatense) and English.

**Everything about Sillo lives at → https://paleto.gg/sillo.html**
(guides, changelog, feedback, moments)

This repository only hosts the release downloads (the zips under
[Releases](../../releases)). Sillo self-updates from here — ask-first,
SHA-256-verified, with a backup of your data every time.
